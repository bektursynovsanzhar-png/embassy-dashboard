# Embassy — автоматический дашборд

Живой дашборд с полным набором ключевых показателей по проектам. Ты как
директор держишь одну ссылку в закладках — она всегда показывает
актуальные цифры.

## Что на дашборде

1. **Приход: план/факт** — общий и по проектам, кольца прогресса
2. **Отставание/опережение в тенге** — прямо в карточке под кольцом
3. **Сравнение с предыдущим периодом** — «▲/▼ X% к пред. периоду»
4. **Подсветка тревожных проектов** — красная рамка у карточки, если
   выполнение плана периода ниже 50% (порог настраивается в коде,
   переменная `ALERT_THRESHOLD`)
5. **Прогноз на конец месяца** — экстраполяция по текущему темпу
   (не зависит от фильтра периода — всегда считает от начала текущего
   календарного месяца)
6. **Динамика прихода по дням** — стековый график по проектам
7. **Воронка** — заявки → записи на ПУ → дошли → продажи, с конверсией
   на каждом шаге
8. **Лиды, бюджет, CPL** — план/факт по таргету и органике отдельно,
   потраченный бюджет, цена заявки
9. **Тренды CPL и среднего чека по дням** — графики, чтобы видеть рост
   цены лида или падение чека раньше, чем это скажется на выручке
10. **Отказы лидов по причинам** — вне рабочего времени / недозвон /
    без номера / непрофильный, в штуках и % от заявок
11. **Продажи по источникам** — таргет vs органика: количество, сумма,
    средний чек, доля
12. **ПУ и продажи план/факт** — по каждому проекту
13. **СММ/Instagram** — просмотры, подписчики, охват, вовлечённость
    (блок скрывается сам, если файла `data/smm.csv` нет)

Всё — с фильтром периода (сегодня / вчера / 7 дней / неделя / месяц /
прошлый месяц / свой период), пересчитывается в браузере мгновенно.

## Как это устроено

```
Сотрудники → Google Форма → Google Таблица (лист "daily")
                                  │ (Apps Script, авто при отправке формы)
                                  ▼
                        data/daily.csv в этом репозитории
                                  │ (GitHub Actions, авто при обновлении)
                                  ▼
                            index.html (дашборд)
                                  │ (GitHub Pages)
                                  ▼
                     https://<username>.github.io/<repo>/
```

`data/plans.csv` (план) и `data/smm.csv` (СММ) обновляются отдельно —
не каждый день, поэтому для них отдельные функции в Apps Script
(`syncPlansToGitHub`, `syncSmmToGitHub`), запускаются вручную по
необходимости.

## Настройка с нуля

### 1. Репозиторий
Загрузи все файлы этой папки в новый **публичный** репозиторий на GitHub.

### 2. GitHub Pages
Settings → Pages → Source: **Deploy from a branch** → **main** / **(root)** → Save.

### 3. Права GitHub Actions на запись
Settings → Actions → General → Workflow permissions → **Read and write permissions** → Save.

### 4. Проверить сборку
Actions → "Build dashboard" → Run workflow. Через минуту дашборд появится по ссылке
`https://<username>.github.io/<repo>/`.

### 5. Форма для ежедневного ввода
Google Форма, поля **строго в этом порядке**:

| # | Поле | Тип |
|---|---|---|
| 1 | Дата | Дата |
| 2 | Проект | Список: Варламова / Самал / Астана / Онлайн |
| 3 | Канал | оффлайн / онлайн |
| 4 | Лиды с таргета | Число |
| 5 | Лиды органика | Число |
| 6 | Бюджет потрачено, тг | Число |
| 7 | Отказ: вне рабочее время | Число |
| 8 | Отказ: без номера | Число |
| 9 | Отказ: недозвон | Число |
| 10 | Отказ: непрофильный | Число |
| 11 | Записей на ПУ | Число |
| 12 | Дошли на ПУ | Число |
| 13 | Продаж с таргета, шт | Число |
| 14 | Продаж с органики, шт | Число |
| 15 | Приход с таргета, тг | Число |
| 16 | Приход с органики, тг | Число |
| 17 | Доплаты, тг | Число |

1. Ответы → создать таблицу → переименовать лист в `daily`
2. Расширения → Apps Script → вставить код из `scripts/apps_script_sync.gs`
3. Настройки проекта → Свойства скрипта:
   - `GITHUB_TOKEN` (GitHub → Settings → Developer settings → Personal access
     tokens → Generate new token, права **repo**)
   - `GITHUB_REPO` — например `username/embassy-dashboard`
   - `GITHUB_BRANCH` — `main`
4. Триггеры → Add Trigger → `syncToGitHub`, From spreadsheet, On form submit

### 6. План на месяц
`data/plans.csv`: `month, project, channel, plan_revenue, plan_leads_target,
plan_leads_organic, plan_budget, plan_pu_records, plan_sales_count`.
Впиши план на нужный месяц и запушь в репозиторий (или веди на отдельном
листе "plans" в той же Google Таблице и запускай `syncPlansToGitHub()`
вручную при изменении).

### 7. СММ (опционально)
Если хочешь блок СММ на дашборде — заполняй `data/smm.csv`:
`date, views, new_followers, reach, engagement`. Можно вручную (раз в день/
неделю копировать из Instagram Insights) или через отдельный лист "smm" +
`syncSmmToGitHub()`. Если файла нет — блок просто не показывается.

## Структура файлов

- `data/daily.csv` — ежедневные факты (авто из формы)
- `data/plans.csv` — план по проектам на месяц (вручную)
- `data/smm.csv` — данные СММ (опционально)
- `scripts/build_dashboard.py` — собирает `index.html` из данных
- `scripts/apps_script_sync.gs` — мост Google Sheets → GitHub (3 функции)
- `.github/workflows/build.yml` — автопересборка (по пушу + раз в час + вручную)

## Добавить новый проект

1. Добавь строку в `data/plans.csv` с новым названием проекта
2. Добавь этот же проект как вариант в Google Форме
3. Дашборд подхватит его автоматически, в коде ничего менять не нужно

## Настроить порог подсветки

В `scripts/build_dashboard.py`, в самом HTML/JS-шаблоне, есть строка:
```js
const ALERT_THRESHOLD = 50; // % от плана, ниже которого подсвечиваем карточку
```
Поменяй число и пересобери (`python3 scripts/build_dashboard.py`) — или
просто запушь изменение, Actions пересоберёт сам.
