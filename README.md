# Embassy — автоматический дашборд

Живой дашборд с ключевыми показателями по проектам (Варламова, Самал, Астана,
Онлайн — можно добавлять свои). Ты как директор держишь одну ссылку в закладках —
она всегда показывает актуальные цифры.

## Что на дашборде

1. **Приход: план/факт** — общий и по каждому проекту, кольца прогресса
2. **Динамика прихода по дням** — стековый график, каждый проект своим цветом
3. **Отставание / опережение плана** — сразу в тенге, по каждому проекту и итого
4. **Лиды, бюджет и CPL** — лиды с таргета и органика (план/факт), потраченный
   бюджет (план/факт), цена заявки (план/факт, посчитана автоматически)
5. **Пробные уроки (ПУ)** — план/факт записей, дошли, доходимость
6. **Продажи** — план/факт по количеству и по сумме

Всё это — с фильтром периода (сегодня / вчера / 7 дней / неделя / месяц /
прошлый месяц / свой период) прямо в браузере, без перезагрузки.

## Как это устроено

```
Сотрудники → Google Форма → Google Таблица (лист "daily")
                                  │ (Apps Script, авто при каждой отправке формы)
                                  ▼
                        data/daily.csv в этом репозитории
                                  │ (GitHub Actions, авто при обновлении файла)
                                  ▼
                            index.html (дашборд)
                                  │ (GitHub Pages)
                                  ▼
                     https://<username>.github.io/<repo>/
```

План (`data/plans.csv`) обновляется отдельно, вручную — в начале месяца или
при пересмотре целей (не каждый день, поэтому отдельный процесс).

## Настройка с нуля

### 1. Репозиторий
Загрузи все файлы этой папки в новый **публичный** репозиторий на GitHub.

### 2. GitHub Pages
Settings → Pages → Source: **Deploy from a branch** → **main** / **(root)** → Save.

### 3. Права GitHub Actions на запись
Settings → Actions → General → Workflow permissions → **Read and write permissions** → Save.

### 4. Проверить сборку
Actions → "Build dashboard" → Run workflow. Через минуту дашборд появится по ссылке
`https://<username>.github.io/<repo>/`.

### 5. Форма для ежедневного ввода
1. Google Форма, поля **строго в этом порядке**:
   - Дата
   - Проект (список: Варламова / Самал / Астана / Онлайн)
   - Канал (оффлайн / онлайн)
   - Лиды с таргета (число)
   - Лиды органика (число)
   - Бюджет потрачено, тг (число)
   - Записей на ПУ (число)
   - Дошли на ПУ (число)
   - Продаж, шт (число)
   - Приход, тг (число)
   - Доплаты, тг (число)
2. Ответы → создать таблицу → переименовать лист в `daily`
3. Расширения → Apps Script → вставить код из `scripts/apps_script_sync.gs`
4. Настройки проекта → Свойства скрипта:
   - `GITHUB_TOKEN` (GitHub → Settings → Developer settings → Personal access
     tokens → Generate new token, права **repo**)
   - `GITHUB_REPO` — например `username/embassy-dashboard`
   - `GITHUB_BRANCH` — `main`
5. Триггеры → Add Trigger → `syncToGitHub`, From spreadsheet, On form submit

### 6. План на месяц
Открой `data/plans.csv`, впиши план по каждому проекту на нужный месяц:
`month, project, channel, plan_revenue, plan_leads_target, plan_leads_organic,
plan_budget, plan_pu_records, plan_sales_count` — и запушь в репозиторий
(или используй `syncPlansToGitHub()` из apps_script_sync.gs, если ведёшь план
тоже в Google Таблице, на отдельном листе "plans").

## Структура файлов

- `data/daily.csv` — ежедневные факты (авто из формы)
- `data/plans.csv` — план по проектам на месяц (вручную)
- `scripts/build_dashboard.py` — собирает `index.html` из данных
- `scripts/apps_script_sync.gs` — мост Google Sheets → GitHub (факт + план)
- `.github/workflows/build.yml` — автопересборка (по пушу + раз в час + вручную)

## Добавить новый проект

1. Добавь строку в `data/plans.csv` с новым названием проекта
2. Добавь этот же проект как вариант в Google Форме
3. Всё — дашборд подхватит его автоматически, ничего в коде менять не нужно
